# 清影 2.6 · GPT 去鳞纹

Windows x64 便携版。完整解压 `Qingying-2.6-Windows-x64.zip` 后运行“清影图片降噪.exe”，保留 `_internal` 文件夹。

## 新增

- GPT 去鳞纹 · ESRGAN + L0：预缩、动漫模型重建、原尺寸恢复与 L0 平滑。
- GPT 去鳞纹 · CUGAN + L0，以及无需显卡的纯 L0 平滑。
- 轻柔 / 推荐 / 强力三档；推荐档对应预缩 60% 与 L0 0.001。
- 新模式沿用原图 / 结果 / 分割对比、透明通道、PNG / JPG / WebP 保存和批量处理。
- 引擎、模型与许可证内置，运行时不下载模型、不上传图片；原有六种算法保留。

优先试“GPT 去鳞纹 · ESRGAN + L0”的推荐档。L0 在 CPU 上运行，大图较慢；模型重建需要支持 Vulkan 的显卡。新模式最多 800 万像素。强力档可能抹掉淡阴影或细字，可改用轻柔档。

## 验证范围

本机已验证三个新模式的全部九种强度组合、原尺寸与 RGBA 透明通道、界面工作线程、PNG 保存和双图批量。L0 在测试数组上与上游 CPU 实现逐像素一致；打包程序及桌面安装目录中的便携程序均已通过九算法自检。这些测试证明本机功能流程可用，不代表已经在所有显卡或用户图片上完成画质验收。

本次接入核心算法与三档预设，未移植上游网页界面、APISR、局部保护笔刷或连续微调。NCNN 与上游 PyTorch 推理输出可能有像素差异，不保证完整重建流程逐像素一致。
