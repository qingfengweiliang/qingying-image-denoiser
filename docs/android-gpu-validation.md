# Android GPU 与进度验证

版本：1.1.0-preview（versionCode 2）。基于仓库提交 `c64c226a58da124a6dba4c6511e303c82c4d5da8` 改进；历史 Android 1.0.0 的签名和模拟器记录保留在 [原验证记录](android-validation.md)。

## 检查范围

1. JDK 实际编译并执行进度计算测试：图块边界、Real-CUGAN 五轮计数、4× 两轮的图块权重、速度 / 剩余时间、GPU 重试后的重新计时和异常计数保护。
2. Python 图像回归：原有降噪与透明度、PNG/JPEG/WebP 导出；新增进度回调不会改变图像输出的检查。
3. Android 自动构建：ARM64 / x86_64 Debug APK、仪器测试 APK 编译和 Lint。
4. C++ 原生回归：两种引擎的 33 组模型组合，分别执行 CPU 和 Mesa 软件 Vulkan；验证每个已完成图块步骤只计数一次、最终计数完整、图像非空及缺失模型错误清理。

具体执行结果以本次 PR 的 Android APK 工作流日志为准。仪器测试源码覆盖 CPU / 自动模式、进度、透明度与导出；仅编译测试 APK 不表示已在设备上运行。

## 尚未验证

- 本次没有连接实体 ARM64 手机，没有手机端 GPU / CPU 同图基准。
- 未验证各品牌驱动、低内存设备、16 KB 内存页设备、长时间发热降频和后台切换。
- 未用原正式私有密钥签名新 Release，未发布新的正式安装包。
- 可恢复的 ncnn 返回错误可回退 CPU；驱动崩溃或系统终止进程不在普通异常恢复范围内。

## 真机验收建议

同一张插画和照片分别执行“自动”与“CPU”，固定算法、强度和倍率，记录设备、系统、GPU 名称、总耗时和完成后 MP/秒。检查输出尺寸、颜色、透明边缘和分块接缝。覆盖 Waifu2x 1/2/4×、Real-CUGAN 1/2/3/4×，确认百分比没有提前结束，4× 能连续统计两轮。

GPU 不可用设备应显示 CPU；GPU 可恢复错误重试时应清楚显示回退，当前轮计数重置并重算速度；手动 CPU 模式下不得报告为 GPU。再验证 PNG / JPEG / WebP 导出、重新导入、旧结果保护、低内存拒绝及同签名覆盖安装。
