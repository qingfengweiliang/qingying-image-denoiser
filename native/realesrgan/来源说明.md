# Real-ESRGAN 动漫引擎

清影 2.6 用于 GPT 去鳞纹的原生后端。官方 `realesrgan-x4plus-anime`（x4plus anime 6B）模型以 4× 重建预缩图片，再恢复输入尺寸并做 L0 平滑。

- 引擎：https://github.com/xinntao/Real-ESRGAN-ncnn-vulkan/releases/tag/v0.2.0
- 模型：https://github.com/xinntao/Real-ESRGAN/releases/tag/v0.2.5.0
- 处理方案：https://github.com/CXP-2024/gpt-anime-denoise
- 引擎许可：本目录 `LICENSE`
- Real-ESRGAN 许可：`../../licenses/Real-ESRGAN-LICENSE.txt`

EXE、DLL 和模型权重随 Windows 便携包提供；仓库保留模型参数与说明。下载 2.6 ZIP 后可运行 `python scripts/restore_native.py ZIP文件路径` 恢复所有原生文件。

本后端使用 Vulkan，L0 使用 NumPy CPU；与上游 PyTorch 后端不保证整个处理流程逐像素一致。
