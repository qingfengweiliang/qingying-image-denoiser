This application uses the unmodified Qt/PySide6 runtime supplied by the Qt for Python project.
The open-source LGPLv3 option is used for the applicable Qt modules and Python bindings.
LGPLv3 and its referenced GPLv3 text are provided in this directory.
Other third-party components retain their respective licenses.

Qt runtime libraries are dynamically loaded from _internal/PySide6. They are not statically linked.
Application sources (app.py, glass_ui.py, engine.py) and requirements.txt are included so the
application can be rebuilt with a compatible modified Qt/PySide6 runtime. No restriction is
imposed by this application on modification of LGPL-covered libraries or reverse engineering
for debugging such modifications. Keep compatible DLLs and Python bindings together.
